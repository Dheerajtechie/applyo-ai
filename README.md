# Turbo Video Speed Controller Chrome Extension

A powerful Chrome extension that increases and controls video playback speed on almost any website.

## Features

- Increase speed up to 16x
- Floating speed controller
- Keyboard shortcuts
- Modern popup UI
- Works on YouTube, Netflix, Udemy, Coursera and more
- Saves preferred playback speed automatically

## Keyboard Shortcuts

- Press `D` → Increase speed
- Press `S` → Decrease speed
- Press `R` → Reset speed to 1x

## Installation

1. Download or clone this repository
2. Open Google Chrome
3. Go to `chrome://extensions`
4. Enable `Developer Mode`
5. Click `Load unpacked`
6. Select the project folder
7. Done
